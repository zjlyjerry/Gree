# 杭州舒享暖通工程有限公司官网

这是一个现代化的暖通工程公司官网静态页面，采用响应式设计，适配各种设备。

## 文件结构

```
web_test/
├── index.html      # 主页面
├── styles.css      # CSS样式文件
├── script.js       # JavaScript交互功能
└── README.md       # 说明文档
```

## 功能特性

### 🎨 设计特点
- **现代化设计**：简洁、专业的视觉风格
- **响应式布局**：完美适配桌面、平板、手机
- **流畅动画**：滚动动画、悬停效果、过渡动画
- **渐变色彩**：使用现代CSS渐变效果

### 📱 页面结构
1. **导航栏**：固定顶部，支持移动端汉堡菜单
2. **横幅区域**：全屏展示，包含公司标语和行动按钮
3. **关于我们**：公司介绍、统计数据、形象展示
4. **服务区域**：四大核心服务卡片展示
5. **联系方式**：联系信息表单和公司地址
6. **页脚**：快速链接、社交媒体、版权信息

### ⚡ 交互功能
- 移动端导航菜单切换
- 平滑滚动导航
- 滚动触发动画
- 数字统计动画
- 表单提交处理
- 返回顶部按钮
- 键盘导航支持

## 使用方法

### 1. 直接打开
双击 `index.html` 文件即可在浏览器中查看网站。

### 2. 本地服务器（推荐）
使用本地服务器可以获得更好的体验：

```bash
# 使用Python
python -m http.server 8000

# 使用Node.js (需要安装http-server)
npx http-server

# 使用PHP
php -S localhost:8000
```

然后在浏览器中访问 `http://localhost:8000`

## 自定义修改

### 修改公司信息
编辑 `index.html` 文件：

1. **公司名称**：搜索 "舒享暖通" 进行替换
2. **联系方式**：修改 `#contact` 部分的电话、邮箱、地址
3. **服务内容**：修改 `.service-card` 中的服务描述
4. **关于我们**：修改 `.about-text` 中的介绍文字

### 修改颜色主题
编辑 `styles.css` 文件中的CSS变量：

```css
:root {
    --primary-color: #e65100;    /* 主色调（暖橙色） */
    --secondary-color: #00897b;  /* 辅助色（青色） */
    --accent-color: #ff8f00;     /* 强调色（金色） */
    /* ... 其他颜色变量 */
}
```

### 添加图片
1. 在项目文件夹中创建 `images` 文件夹
2. 将图片放入文件夹中
3. 在HTML中使用 `<img>` 标签引用图片

例如，替换关于我们部分的图片占位符：
```html
<div class="about-image">
    <img src="images/company.jpg" alt="公司形象" style="width: 100%; border-radius: 1rem;">
</div>
```

### 添加新页面
1. 创建新的HTML文件（如 `about.html`）
2. 在导航栏中添加链接
3. 复制页头和页脚代码
